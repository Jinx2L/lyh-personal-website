# 李意慧个人作品集网站设计规格

日期：2026-08-26

## 1. 项目目标

从零搭建一个适合 PC 端展示的个人作品集网站，用于呈现李意慧作为视觉设计师 / UI 设计师的专业能力、工作经历和核心项目。网站采用暗色、高级、克制、有科技感的视觉语言，但避免常见模板化作品集的粒子特效、霓虹渐变和堆叠式卡片感。

首版重点是建立可运行、可预览、便于后续持续替换真实素材和优化动效的 React + Vite 基础架构。

## 2. 设计依据

### 文件1：Prisma Creative Studio 风格参考

提取其视觉方法而不直接复刻品牌：

- 黑色背景与暖灰/米白文字形成高对比但不刺眼的视觉体系。
- 超大字号标题作为首屏核心视觉，而不是依赖复杂装饰。
- 大尺寸圆角媒体区域营造电影感和沉浸感。
- 导航、按钮、标签都保持克制，避免传统“科技网站”式高亮描边。
- 动效以文字上拉、淡入、滚动显现和轻微视差为主。
- 卡片使用深灰而非纯黑分层，强调布局节奏与内容比例。

## 3. 视觉方向

设计关键词：Dark Editorial × Digital Product。

视觉比例约为：

- 70% 电影感 / 编辑排版
- 30% 理性的数据产品与系统设计气质

### 色彩

- 页面背景：#050505 / #000000
- 一级卡片：#111111
- 二级卡片：#191919 - #212121
- 主文字：#E7E4D6
- 次文字：rgba(231, 228, 214, 0.58)
- 弱化文字：rgba(231, 228, 214, 0.32)
- 强调色：首版仅使用极少量低饱和暖绿色 / 黄绿色作为状态或交互提示，不让它成为大面积品牌色。

### 字体

首版优先使用系统无衬线字体栈，避免依赖特殊本地字体。英文字母标题使用高字重和紧字距形成视觉识别；中文保持克制、清晰、现代。

如后续用户提供品牌字体，再独立替换。

### 版心

- PC 最大内容宽度：约 1700px
- 1920px 屏幕时左右留白约 110px
- Hero 媒体区域可略宽于正文版心，强化首屏沉浸感
- 使用 clamp()、CSS Grid 与百分比布局提前支持缩放屏幕

## 5. Hero 首屏

### 布局

高度 100vh。外层保留适度边距，内部为大尺寸圆角沉浸区域。

顶部为悬浮式极简导航；中下部为超大主标题；右下区域放职业定位和 CTA。

### 动态背景方案 B

不使用 Prisma 原视频。通过浏览器原生 CSS + React 动画构建抽象动态背景：

- 深黑到炭灰渐变底色
- 2–3 个缓慢移动的大尺寸柔光区域
- 低透明度噪点纹理
- 极轻的网格 / 光影折射
- 鼠标移动只产生非常轻微的景深偏移，不做追光圆斑

首版不引入 WebGL / Three.js，以保证性能和后续维护成本。

### 文案

主标题：PORTFOLIO

辅助定位：
Visual Designer / UI Designer

中文副标题：
把复杂业务转化为清晰、有价值的数字体验。

CTA：联系我

### 动效

- 标题按词或字母组上拉出现
- 副标题与 CTA 延迟淡入
- 背景光影持续以 12–20 秒周期缓慢运动
- 首屏滚动离场时产生非常轻微的视差

## 7. Selected Works

### 展示方式

PC 端采用 2 列大卡片布局，四张卡形成错落节奏。图片比例与高度不完全一致，避免网格模板感。

卡片默认显示：

- 项目编号
- 项目名称
- 项目类型
- 年份
- 一个关键成果或角色描述
- 大尺寸视觉占位图

悬停时：

- 图片 1.02–1.04 倍轻微放大
- 卡片标题与箭头轻微位移
- 背景明度变化不超过 8%

## 11. 响应式策略

首要目标是 PC，但从首版保证：

- 1920px：约 1700px 版心
- 1440px：自动收窄，主要结构不变
- 1024–1280px：导航缩小间距，卡片保持可读
- < 900px：Selected Works 与 Expertise 转单列 / 双列

不以手机端完整视觉打磨作为首版验收重点，但不会出现明显溢出和导航错位。

## 12. 性能与可维护性

- 抽象动态背景使用 CSS / Framer Motion，不引入 Three.js
- 动画仅使用 transform / opacity 为主
- 尊重 prefers-reduced-motion
- 图片位置使用统一对象模型，后续可直接替换本地 WebP / AVIF
- 不使用远程 Prisma 素材作为最终资源
- 不引入不必要的状态管理库

## 13. 首版验收标准

完成后应满足：

1. npm install 后可通过 npm run dev 启动。
2. 单页 5 个模块完整存在并可导航。
3. Hero 有原创抽象暗色动态背景，而非参考网站视频。
4. 核心内容与简历一致，不虚构项目成果。
5. PC 端 1920px 下版心约 1700px，视觉结构完整。
6. 1440px 与 1280px 下无明显布局错位。
7. 项目图片和人物图都有清晰、独立、易替换的资源接口。
8. 样式具备暗色、克制、编辑感和轻科技感，不呈现模板网站气质。
